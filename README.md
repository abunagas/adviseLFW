# LINTIVO - Premium Web Solutions

Modern, high-performance, and aesthetically pleasing website for LINTIVO.

## 🚀 Deployment

This website is configured for direct deployment via **GitHub** and **Netlify**.

### How to Deploy
1. **GitHub**: Every push to the `main` branch automatically triggers a new build.
2. **Netlify**: Ensure your repository is connected to Netlify. The `netlify.toml` file handles the build settings automatically.

## 🛠️ Development

### Local Setup
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## ✨ Features
- **Page-based Scroll Snapping**: Immersive scrolling experience.
- **Dynamic Particle Backgrounds**: Interactive and subtle animations.
- **Glassmorphism Design**: Premium, modern visual style.
- **Multi-language Support**: Lithuanian and English.
